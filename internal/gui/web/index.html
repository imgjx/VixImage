快速上手

  • 在 上游模型 添加图片模型与大模型（仅多模态）：可填「对 Agent 的介绍」「多尺寸」，LLM 需设 max_tokens（小上下文模型务必配置）。
  • 在 我的模型 创建 Agent：基架模型 + 图片模型（每个配「单次生图消耗步数」）+ 总步数预算（默认 100）+ 步数耗尽策略 + 风格模式。
  • 用 Playground 直接试玩上游生图；用 API POST /v1/agents/run 调起（可传参考图，ref:N 嵌入编辑）。
  • 自循环 Agent：技能全是图像工作。每次大模型请求 = 1 步，一轮可一次执行多个工具（建画布 / 生图 / 加删改图层 / 抠图虚化旋转斜体…），带「查看作品」与「完成信号」两个链底工具。Agent 能反复观摩自己的成片、多轮迭代，而非一次性吐出全部排版。质量铁律：成片必须完美、只允许极细微瑕疵，完成或大改后主动查看自检偏移；系统级强制 view：提交产物前由系统拦截 finish，强制回看当前成片，看过并确认才交付。
  • 更主动的创意实现 + 画中画透视贴合：主提示词教 Agent 别平铺贴图，把参考图变成画面里的「物件内容」——斜放设备屏幕 / 相框 / 橱窗 / 画中画。用 gen{ref:0} 或扩展 ref（产物 id / 图片网址，把任意已有图再做图生图）生成场景；img 用 persp/shear 把平面贴图映射成斜放表面、真正贴到屏幕上（比单纯 rot 更贴合），再叠加 radius/border/shadow 嵌入。例如「给一张参考图，做男孩盯着一台斜放的电脑、屏幕里正是这张参考图」。
  • 写死学习数据 + 缓存省钱：主提示词与 Few-shot 学习数据都是写死常量，拼成恒定 system 前缀（主提示词在前、学习数据在后），同模型每轮一致可命中上游缓存；动态内容全放后面的 user 消息。「我的模型」可独立开关学习数据。
  • 中间产物可管理：用户参考图也进产物表并标注；复制产物（存档 / 分叉 / 复用）、回滚编辑（动作级撤销，只退排版不退素材）、查看图层清单，改坏了随时回退重来。
  • 上下文按 主提示词 → 紧凑上下文（剩余步数 + 图像模型列表）→ 产物表 → 上一轮结果（仅生图/查看有输出图）→ 用户要求 拼接；编辑轮只回「是否成功」，保持紧凑。
  • 全链路无兜底：解析失败 / 非法工具 / 生图失败 / 渲染失败一律直接报错；提示词防注入，拒绝「满屏重复字符」类爆量输出。中间产物 100% 删除。
  • 调用概述支持分页与每步思考轨迹；API 加 "trace": true 可附带每步短 ThinkFlag。
