创建我的模型（Agent）

Agent 自循环：每次大模型请求算 1 步，每次生图额外消耗该图像模型配置的「单次步数」（下方「步数」列，默认 30）。编辑/查看/完成不单独计步。上下文会告诉模型剩余步数。步数不必用完，收到完成信号即结束。
耗尽策略按每个模型独立配置。fail = 未完成即失败；partial = 若画布已建立则返回当前半吊子成片。
开启后，基座模型会先推演需求、构图与配色，再输出工具；受模型 max_tokens 限制，小上下文模型建议关闭。
示范教 Agent「一轮铺完整版」「参考图做斜放屏幕画中画」「大改后自检」等创意思路与输出格式。主提示词与学习数据都写死、位于最前的 system 前缀，同模型恒定可命中上游缓存省钱；关闭则只发主提示词。动态内容（步数/产物表/用户要求）一律放在后面。
